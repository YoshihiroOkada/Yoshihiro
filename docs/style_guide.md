# STYLE GUIDE（講座 step 5 / 画像プロンプト visual_system）

採用案: `docs/directions.html` の A「灯」。値の元は `brand/tokens.json`。

## 色（hex）
| 役割 | hex | 使い方 |
|---|---|---|
| 地 | `#1C1915` | 夜の空気・背景の一番暗い所 |
| 面 | `#29241F` | 墓石・柱・床の面 |
| 線 | `#4A433B` | 輪郭・木の枝・影の線 |
| 補助 | `#A39A8E` | 月・石の明るい面・字幕 |
| 文字 | `#F2EDE4` | 画面のキーワード |
| アクセント | `#E8823A` | **光だけ**（カボチャの灯・ろうそく・強調行）。それ以外に彩度の高い色は使わない |

## 書体（2つ）
- 表示（キーワード）: Noto Serif JP 700。字間 +20。左寄せ（16:9）/ 中央（9:16・1:1）
- 字幕: Noto Sans JP 500。中央。下端12%の帯（地色 85%）の上

## 絵（すべて ChatGPT＝OpenAI 画像APIで生成。図形で代用しない）
- 画風: 切り絵・影絵芝居のような **2.5D の平面イラスト**。紙の質感と細かい粒子のノイズ（グレイン）。輪郭ははっきり。
- 光: 光源はアクセント色のみ。にじみ（グロー/ブルーム）を描かない。
- 禁止: 文字・ロゴ・ネオン・グラデーションの空・レンズフレア・パーティクル・3Dのツルツルした塊・写真風。
- 背景（プレート）は 3:2 の一枚絵。小物は **透過PNG**、物が全部見える、地面の影なし、中央配置。
- 同じ物は同じ形（例: 仮面は冒頭・最後・サビで同じデザイン）。

## ショットとトランジション
- 1ショット = 歌詞1行（約3〜4秒）。2〜4秒ごとに必ず新しいこと（構図の変化・キーワード）が起きる。
- 最初の2秒: 一番強い1枚の絵（墓の上に置かれた仮面）。最後: 同じ絵に戻る。
- トランジションは「カメラの構図変更」だけ（横移動＋ズーム、行と行の間の 0.8 秒以内）。ディゾルブ・ワイプ・フラッシュ無し。
- サビへの切り替え: カボチャの灯が昇り、カメラが上へ追い、舞踏会へ降りる（物を差し替えずに場所を移動）。

## カメラ
- 閉形式スプリング、減衰比 1 以上（バウンス無し）。文字を読んでいる間は完全に静止。手ブレ・ゆらぎ無し。

## 文字の出入り
- 入り: 文字ごとに 0.03 秒ずらし、下から 1/4 文字ぶん上がって止まる（オーバーシュート無し）。全部同時のフェードインはしない。
- 出: まとめて 0.35 秒で消える。次の文字は前の文字が消えてから。
