# IDEA（workflow 1）

## 1文のアイデア
仮面の下に隠した本当の声が、墓場の夜から舞踏会の光へ、歌うほどに顔を出していく。

## 見た人がわかること（OUTCOME）
「この曲は、仮面をかぶった夜の物語で、サビで本音が出る」と自分の言葉で言える。

## 入力（inputs の読み替え）
| 項目 | このMV |
|---|---|
| TOPIC | 曲の物語（ハロウィンの夜 → サビで仮面舞踏会） |
| AUDIENCE | 歌い手のリスナー。曲をまだ知らない人も含む。「ハロウィン曲＝にぎやか」と思っている |
| OUTCOME | 上の1文が言える |
| 長さ | 曲の長さ（ショートは 30〜90 秒の切り抜き） |
| 形式 | 16:9 マスター → 9:16 と 1:1 を作り直し（ただの切り抜きではなく再構成） |
| ブランド・参考 | `brand/`（トークン）、`refs/`（参考画像）、`screens/`（立ち絵・背景イラストなど本物の素材） |

## discovery
- **この映像が答える1つの問い（視聴者の言葉で）:** 「この子は、なんで仮面をかぶってるの？」
- **必須 / カット:** 必須 = 夜の墓場、仮面、サビの舞踏会、歌い手の立ち絵。カット = 宇宙、ネオン、ライブ会場、コウモリの群れ。
- **フック（多くの人が持っていて、実は違う思い込み）:** 「ハロウィンの歌＝楽しいお祭り」。実は、仮面で本音を隠す歌。
- **比喩:** 「仮面」は曲そのものの比喩なので使う。それ以外の比喩は使わず、本物（立ち絵・歌詞）を見せる。

## story_arc（曲の構成に割り当て）
| 時間 | 役割 | このMV |
|---|---|---|
| 0–10% | Question | 墓場の夜、仮面だけが地面に置かれている絵から始まる（タイトルカードで始めない） |
| 10–35% | Model | Aメロ。墓場を進み、キーワードが1つずつ置かれていく（1拍に1要素） |
| 35–75% | Proof | Bメロ〜1サビ。墓場の灯（アクセント色）が舞踏会の灯へ変わる |
| 75–90% | Turn | 落ちサビ。1つだけ変える: カメラが止まり、仮面が外れる |
| 90–100% | Payoff | 冒頭の「置かれた仮面」の絵に戻る。今度は意味がわかる |
